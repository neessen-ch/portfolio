# Christof Neessen — Portfolio

Persönliches Portfolio von Christof Neessen, Grafik Designer mit UX/UI-Weiterbildung.

**Live:** [neessen.be](https://neessen.be)

## Tech-Stack

- HTML / CSS / JavaScript (Vanilla, kein Build-Step)
- Schriftart: [Sora](https://fonts.google.com/specimen/Sora) (Google Fonts)
- Hosting: Cloudflare Pages
- (Geplant) Inhaltspflege: Sanity CMS

## Lokale Entwicklung

Einfach mit einem statischen Webserver öffnen:

```bash
python3 serve.py
# Webseite: http://127.0.0.1:8765
```

## Struktur

```
portfolio/
├── index.html        # Haupt-HTML mit allen Sektionen
├── styles.css        # Komplettes Design-System
├── script.js         # Animationen, Lightbox, Filter
└── assets/           # Bilder & Logos
```
